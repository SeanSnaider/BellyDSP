# BellyDSP 0.1.0

The first public version.

- Three NAM amp slots (load any amp-only `.nam` capture), a three-mic cab with your own IRs, gates, drive pedals, and the full effects chain.
- The tuner, scenes, presets, and MIDI footswitch control.
- **Updates install themselves** from now on: BellyDSP checks once a day and installs a new version when you quit.
